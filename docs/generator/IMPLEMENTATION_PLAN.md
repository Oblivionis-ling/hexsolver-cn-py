# 种子逐步求解器开发清单与版本规划

本文档定义从当前截图求解工作台演进到“输入种子、复刻地图、手动同步局面、询问下一步”的实施路线。

## 1. 产品目标

用户输入 `种子号 + 难度` 后，程序生成与指定 Steam 版本完全一致的初始地图。用户在可视化棋盘上把已经打开或标黑的格子同步到当前游戏状态，然后请求一个必然成立的下一步，并查看中文理由。

当前逆向基线：

- Steam Build ID：`5455383`
- Unity：`5.6.3f1`
- 游戏程序集 SHA-256：`835DEC694D7685809EDAC963E0F47306AD4300C7D7C9C555AD457F20EFAA8083`
- Hard 生成器：`LevelGenerator`，验证器：`Solver / Set`
- Easy 生成器：`OldLevelGenerator`，验证器：`MarvinHexcellsSolver`

## 2. 不可妥协的验收原则

- 只有同一个种子在原游戏与本工具中逐格、逐线索一致，才标记为“生成器已验证”。
- 近似生成、相似难度或“能解但地图不同”不算完成。
- 完整答案必须与公开盘面隔离。逐步求解器只能使用玩家当前可见信息。
- 每个建议都必须是必然步；无法证明时返回“当前没有可证明步骤”，不猜。
- Easy 与 Hard 分别实现和验收，不能用一套近似算法冒充两套生成器。

## 3. 模块划分

```text
seed + difficulty + game build
              |
              v
     SeedGeneratorBackend
              |
              v
 GeneratedPuzzle(public board + private answer)
              |
              v
      InteractiveSession
              |
              v
 HexReasoningSolver.next_step()
              |
              v
    coord + action + Chinese reason
```

## 5. 版本规划

### `0.2.0`：种子工作台基础

- 种子/难度输入和生成器接口。
- 独立棋盘渲染。
- 手动同步格子状态。
- “告诉我下一步”单步求解与中文理由。
- 未通过一致性验证的生成器明确拒绝使用。

### `0.3.0–0.3.1`：原版运行时桥接与完整回放

- Easy/Hard 均通过隔离副本调用原版生成器和内置求解器。
- UI 后台生成最终盘面，支持手动同步和连续询问下一步。
- 原始程序集哈希门禁、诊断命令和 Easy/Hard 冒烟测试。
- 覆盖层下提示按玩家进度释放，完整回放逐步核对原版答案。

### `0.4.0`：默认生成无游戏进程

- Hard `seed -> map` 纯 Python 精确复刻。
- Easy 通过无 Unity 托管宿主直接执行原版生成器与 Marvin。
- 默认产品链路不启动 `Hexcells Infinite.exe`；原版桥只做显式差分。

### `0.4.1–0.4.3`：显示方向与可核查解释

- 修正 Unity 到 Qt 的 Y 轴镜像与左右斜向标签族。
- 所有单步建议展开条件、坐标、数量和算式。
- 全局 forced move 给出错误假设、充分冲突条件和相反假设可行性。
- 长解释使用可滚动说明区承载。

### `0.5.0`：Windows 单文件应用

- 保持 UI 和求解/生成核心逻辑不变，封装为可直接双击的 Windows x64 单文件 EXE。
- 内置可再分发托管宿主，不分发原版程序集或游戏文件。
- 成品自身创建 UI 并验证 Easy/Hard seed 1；Release 提供 SHA-256。

### `0.6.1`：推理阅读与行线索可见性

- 删除界面的步骤历史展示，底层会话历史只用于撤销。
- 扩大可滚动推理原因区域，保证正常窗口和最小窗口都能阅读长解释。
- 强制所有行线索保持可见并位于棋盘上层，为覆盖控件预留安全边距。
- 不修改求解器、生成器和私有答案隔离逻辑。

### `0.6.2`：侧栏精简与完整推理显示

- 将推理正文滚动区与固定按钮栏分离，保证正文不会被操作按钮遮挡。
- 删除重复的“剩余/冲突”统计卡；棋盘右上角计数器继续显示剩余数。
- 缩小手动标记图例并删除按钮下方文字，同时保留 tooltip 与无障碍语义。
- 用 Hard seed 3 第 55 步长全局反证在 `1440 × 1024` 和 `1120 × 760` 下验证首屏、滚动和末尾可见性。
- 不修改求解器、生成器和私有答案隔离逻辑。

### `0.6.3`：种子结果缓存与设置页

- 在默认生成注册表外层加入精确结果缓存，Easy/Hard 后端实现和调用顺序保持不变。
- 缓存键包含 schema、Steam Build、难度、八位种子、后端 ID 和精确性；结果使用经过字段校验的 JSON 和原子写入。
- 缓存损坏、版本不匹配或写入失败时无条件回退到原精确生成器，不阻断主流程。
- 增加可滚动、可继续扩展的设置页，当前提供缓存统计、路径和确认删除。
- 成品验证首次生成写入与第二次请求命中缓存，私有答案继续只用于揭示和测试。

### `0.6.4`：全屏推理末行显示修复

- 修复全屏窗口滚动到推理末尾后最后一行仍被文本视口裁切的问题。
- 使用 `QTextDocument` 根帧底部边距扩展真实滚动范围，不向解释原文附加空行。
- 源码与成品测试都直接验证末尾光标矩形完整可见，并在全屏类宽屏布局回放 Hard seed 3 第 55 步。
- 不修改求解器、生成器、缓存、设置页或私有答案隔离逻辑。

### `0.6.5`：手动标记选中轮廓与原版式鼠标操作

- 保持未知、蓝格、排除按钮原有填充、紧凑尺寸、提示和无障碍语义。
- 三种按钮被选中时分别绘制黑色、橘色、蓝色外轮廓，未选中时保持白色轮廓。
- 源码和成品回归都验证按钮互斥状态、颜色映射及实际位图像素。
- 设置页增加持久化的原版式鼠标操作开关；开启后左键排除、右键标记蓝色，再次同键点击恢复未知。
- 原版式操作开启时禁用三态手动按钮，关闭后恢复当前选中工具，避免两套点击规则冲突。
- 不修改求解器、生成器、缓存、推理显示或私有答案隔离逻辑。

### `0.7.0`：推理数据与棋盘动态联动

- 解析推理原因中的单坐标、坐标数组和三方向行名称，并与当前 `Board` 中的格子、`RowClue` 精确关联。
- 悬停做临时成组高亮，点击固定并加粗文字，再次点击取消；键盘提供等价激活路径。
- 高亮覆盖层不改写格子填充、目标或手动选中描边，切换理由与盘面时自动清理。
- 65 项源码回归和冻结成品冒烟覆盖富文本引用、行/数组联动、减少动态及状态清理。

### `0.7.1`：提示框清理与高亮视觉优化

- 推理引用不再写入 ToolTip，正文视口也会直接消费 `ToolTip` 事件，避免悬停浮层遮挡推理文字。
- 棋盘联动改为外层轻柔光与内层精细轮廓；预览为虚线与一次性 240 ms 淡入，固定为静态实线，减少动态模式不启动计时器。
- 点击/键盘固定、行线索与长数组联动、状态清理、解释原文和求解/生成核心均保持不变。
- 源码回归、原生 Windows Qt 截图和冻结成品冒烟覆盖无提示框、双层几何及虚实线状态。
- 求解器、生成器、缓存和私有答案隔离不变。

### `0.8.0`：可用性与诊断

- 撤销/重做、局面存取和冲突定位。
- `.hexcells` 与 JSON 导入导出。
- 生成器版本/哈希诊断和种子对照报告。

### `1.0.0`：稳定发布

- Easy/Hard 完整支持。
- 回归种子、求解回放、打包运行全部通过。
- 普通用户无需接触游戏文件或命令行即可使用。

## 6. 当前开发状态

当前已完成 `0.7.1`：Hard 为纯 Python 精确移植，Easy 为无 Unity 托管核心；两者默认都不启动游戏。Easy/Hard seed 1–50 及 `00000000`、`99999999` 两个边界种子已全部逐字段一致；显示方向、斜向标签和可核查解释均已完成。Windows x64 单文件应用保留版本化种子缓存、设置页、全屏推理末尾安全区、手动标记轮廓和原版式左右键操作，并把解释中的坐标、坐标组及三方向行线索与棋盘动态关联；0.7.1 取消引用提示框并使用分层高亮。成品会执行真实 UI、引用联动、无提示框与双层覆盖、三种轮廓像素、左右键映射、长解释末尾安全区、设置页、Easy/Hard seed 1 首次写入与再次命中冒烟测试，原版程序集继续保持只读且不进入 Release。
