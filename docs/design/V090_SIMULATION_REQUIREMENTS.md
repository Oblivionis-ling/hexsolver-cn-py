# 0.9.0 模拟推演需求

状态：已完成并通过验收

确认日期：2026-08-25

## 目标

在不改变真实局面、不揭示任何新信息的前提下，让用户从当前盘面建立一个临时假设分支，手动尝试排除格和雷（蓝格），观察这些假设是否与已经公开的线索发生矛盾，并可随时完整返回推演开始时的局面。

## 核心流程

1. 真实盘面加载后，用户点击“开始推演”。
2. 应用保存当前公开盘面快照，进入视觉上明确区分的模拟模式。
3. 用户可把未知格模拟标记为排除、雷（蓝格）或恢复未知。
4. 每次修改后，应用只根据进入推演前已公开的线索和当前模拟假设检查矛盾。
5. 用户可在模拟分支内撤销、重做或重置到推演起点。
6. 用户点击“结束推演”后丢弃整个模拟分支，真实盘面完整恢复。

## 信息隔离

- 模拟标记不会揭示覆盖层下的数字、连续提示或其他新信息。
- 模拟模式不得读取、比较或间接利用生成地图的私有答案。
- 模拟操作不得写入真实会话、正常撤销记录或自动存档。
- 退出应用时默认丢弃未结束的模拟分支，不提供模拟分支恢复。
- `0.9.0` 不提供“把模拟结果应用到真实盘面”。

## 推理与矛盾检测

- 模拟模式中关闭“下一步推理”和应用建议功能，也不在后台为模拟盘面预计算建议。
- 矛盾检测不是下一步求解，只回答“当前模拟假设是否还能满足已公开条件”。
- 若一个模拟填块单独造成公开条件无解，可以高亮该填块及相关线索。
- 若多个模拟填块共同造成矛盾，应高亮一组足以说明冲突的相关填块和线索；除非公开条件能够单独证明，否则不得宣称其中某一格就是实际错格。
- 未发现矛盾只表示当前假设仍可能成立，不表示这些填块已经被证明正确。

## 交互范围

- 进入推演后清除或隐藏真实盘面的当前建议，并禁用下一步推理入口。
- 模拟标记使用半透明或其他清晰但克制的视觉，与真实标记保持明显区别。
- 模式顶部持续显示“正在模拟推演”，并提供撤销、重做、重置和结束推演。
- 首版只支持一条模拟分支，不保存或管理多条分支。

## 验收条件

- 排除、雷（蓝格）和恢复未知均不触发任何新线索揭示。
- 下一步推理在模拟期间不可调用，后台也不启动模拟求解建议。
- 能识别局部计数、行线索和完整公开约束造成的无解，并定位相关模拟填块；整个过程不访问私有答案。
- 重置和结束推演都能精确恢复对应快照，真实盘面、自动存档及正常撤销历史逐字段不变。
- 源码测试和冻结成品冒烟都覆盖进入、标记、矛盾、撤销/重做、重置、退出以及信息隔离。

## 完成证据

- `SimulationSession` 不接收私有揭示数据，只允许修改进入时仍未知的坐标，并维护独立撤销、重做和重置记录。
- `find_public_conflict()` 只接收公开起始盘面和模拟 assumptions；CP-SAT 返回的是充分冲突集合，超时或未知状态不报矛盾。
- UI 在推演期间隐藏下一步与应用建议，以顶部文字、半透明虚线填块、红色双层冲突轮廓和单一退出操作表达临时分支。
- 100 项源码回归通过；原生 Windows Qt 证据见 [`ui-v090-simulation-conflict.png`](ui-v090-simulation-conflict.png)。
- `HexInfiniteSolver-0.9.0-windows-x64.exe` 冻结成品冒烟通过，FileVersion/ProductVersion 均为 `0.9.0`。
